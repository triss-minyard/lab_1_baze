# 📚 LibraryReport

**LibraryReport** — это *консольное приложение* для анализа данных о выдаче книг в библиотеке.
Программа позволяет получать статистику по **выдачам**, **книгам**, **авторам**, **читателям** и **жанрам**.

## Установка 🚀

1. Установите Python 3.10 или выше.
2. Создайте файл `library_report.py`.
3. Добавьте в файл функцию `library_report()`.
4. Запустите программу.

```bash
python library_report.py
```

> ⚠️ **Важно:** программа использует только стандартную библиотеку Python и не требует установки сторонних пакетов.

## Использование 💻

Основная функция программы:

```python
library_report(
    loans,
    date_from,
    date_to,
    genre_filter,
    min_days,
    top_n,
    include_overdue,
    overdue_threshold
)
```

### Параметры функции

| Параметр            | Описание                      |
| ------------------- | ----------------------------- |
| `loans`             | Список выдач книг             |
| `date_from`         | Начальная дата периода        |
| `date_to`           | Конечная дата периода         |
| `genre_filter`      | Фильтр по жанру               |
| `min_days`          | Минимальный срок хранения     |
| `top_n`             | Количество элементов в топе   |
| `include_overdue`   | Учитывать просроченные выдачи |
| `overdue_threshold` | Порог просрочки в днях        |

### Пример запуска

```python
report = library_report(
    loans,
    "2026-09-01",
    "2026-09-30",
    None,
    0,
    3,
    True,
    14
)

print(report)
```

> 💡 **Подсказка:** если `genre_filter` имеет значение `None`, анализ выполняется сразу по всем жанрам.

## Архитектура 🏗️

> 📌 **LibraryReport** получает список выдач, фильтрует данные и формирует итоговый статистический отчёт.

```text
┌─────────────────────┐
│      loans          │
│   Список выдач      │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│     Фильтрация      │
│ дата / жанр / дни   │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│      Анализ         │
│ книги / авторы      │
│ читатели / жанры    │
│ просрочки / сроки   │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│   library_report    │
│   Итоговый словарь  │
└─────────────────────┘
```
